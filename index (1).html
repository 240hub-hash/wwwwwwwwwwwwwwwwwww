ระบบอัปโหลดไฟล์เสียง .OGG ตรงเข้าบัญชี Roblox ของคุณผ่าน Roblox Open Cloud API

ต้องมีสิทธิ์ Permissions: assets:write และ assets:read

ขั้นตอนการอัปโหลดผ่าน Creator Hub (แบบฟรี 100%)

  1. ส่งออกไฟล์เสียงจากแท็บ Timeline Editor เป็นฟอร์แมต OGG Vorbis (ไฟล์จะถูกปรับเป็น 48kHz คุณภาพสูงสุดที่ Roblox แนะนำ)
  2. เปิดเว็บ Roblox Creator Hub Dashboard
  3. ไปที่แท็บ Development Items > Audio
  4. คลิกปุ่ม Upload Asset แล้วลากไฟล์ .ogg ที่ดาวน์โหลดจากโปรแกรมนี้ไปวาง
  5. กดปุ่ม Upload คุณจะได้รับ Asset ID เพื่อนำไปเปิดในเกมได้ทันที
